來源：使用者提供的 Prismaflex Operator’s Manual，Program version 7.xx，G5039912，§12:2–12:3、§13:2–13:3，以及 CRRT 的「Machine Control of Patient Fluid Removal Rate」。M150 的 100 mL/min 是該 set 建議的下限；手冊另述監視器 Run mode 的最低血流可達 10 mL/min，本頁採 set 建議範圍。

PBP 手冊使用分段步距（2、5、10、50 mL/hr），本頁為教學採 50 mL/hr；各項最大值為個別上限，實機還會受治療模式、其他流量與抗凝設定影響。本頁只限制總 effluent 上限，並非完整實機安全限制。

淨脫水與 syringe infusion 固定 0：Qeff = Qpbp + Qdial + Qrep；跨膜超濾 Quf = Qpbp + Qrep。粒子是流路示意，並非血球或溶質質量模型；轉速不是實機 RPM，亦未模擬 TMP、Hct、filtration fraction 或壓力警報。
