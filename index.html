流量驅動動畫

幫浦轉速 ∝ 流量 ÷ 繞行半徑（blood 29、小幫浦 21）；同一顏色粒子連續通過匯合點。液袋容量統一為 5 L，以實際流量積分，時間加速 60 倍。袋滿或用盡時暫停，更換對應液袋後繼續。

來源：使用者提供的 Prismaflex Operator’s Manual，Program version 7.xx，G5039912，§12:2–12:3、§13:2–13:3，以及 CRRT 的「Machine Control of Patient Fluid Removal Rate」。M150 的 100 mL/min 是該 set 建議的下限；手冊另述監視器 Run mode 的最低血流可達 10 mL/min，本頁採 set 建議範圍。

PBP 手冊使用分段步距（2、5、10、50 mL/hr），本頁為教學採 50 mL/hr；各項最大值為個別上限，實機還會受治療模式、其他流量與抗凝設定影響。本頁限制總 effluent 上限，並加入 FF 教學提示，並非完整實機安全限制。

淨脫水與 syringe infusion 固定 0：Qeff = Qpbp + Qdial + Qrep；跨膜超濾 Quf = Qpbp + Qrep。粒子是流路示意，並非血球或溶質質量模型；轉速不是實機 RPM，FF 使用手冊 §5:15：FF = 100 × (PBP + Post) ÷ [0.95 × (1 − Hct/100) × Blood × 60 + PBP]。Dialysate 不計入跨膜超濾量。本頁以 FF >25% 顯示教學警示，FF ≥100% 暫停動畫；兩者不是聲稱實機的硬性設定上限。Hct 的 10–65% 是本頁的教學調整範圍。未模擬 TMP、凝血或完整壓力警報。
